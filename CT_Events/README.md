Codes that effect events in CT

- AlwaysEvent || sets a event to always happen, one of theses should be set at a time

- Event Forver || this makes it so the event never ends

- Dyna Blade Sizing || affects the size of dyna blade

- Tac Sizing || affects the size of tac

- Stadium Prediction Wrong Chance || the odds of the prediction being wrong, or it's always wrong

- Statdium Predication At Start || statdium preduction always occures at the start of the match

- Fog || handles various codes for fog event chance
